Zarra nima?

Zarra — zamonaviy brauzerlar uchun yozilgan 3.2 KB hajmdagi reaktiv UI freymvork. U kichik, lekin to'laqonli: signal'lar, komponentlar va router bitta yadroda.

Nega yana bitta freymvork?

Ko'p loyihalar uchun React yoki Vue — ortiqcha yuk: build pipeline, yuzlab bog'liqliklar, sekundlab yuklanish. Zarra teskari yo'ldan boradi: brauzerda allaqachon bor imkoniyatlardan foydalanadi va faqat yetishmayotgan qatlamni — reaktivlikni qo'shadi.

Zarra kimga mos: landing sahifalar, admin panellar, vidjetlar, va katta freymvork o'rnatishga arzimaydigan har qanday interaktiv sahifa uchun.

Zarra so'zi o'zbekchada "eng kichik bo'lak" degani — freymvork falsafasi ham shunda: minimal yadro, maksimal natija.

Signal'lar

Signal — Zarra reaktivligining yuragi. Bu qiymat saqlaydigan funksiya: argumentsiz chaqirsangiz — o'qiydi, argument bilan — yozadi.

Yaratish va ishlatish

signals.js
import { signal, computed, effect } from 'zarra'

const narx = signal(120_000)
const soni = signal(2)

// hosilaviy qiymat — bog'liqliklar avtomatik kuzatiladi
const jami = computed(() => narx() * soni())

effect(() => console.log(`Jami: ${jami()} so'm`))

soni(3)  // → "Jami: 360000 so'm"

Nima uchun getter/setter emas?

Funksiya-chaqiriq sintaksisi Zarra'ga qaysi kod qaysi signalga bog'liqligini aniq bilish imkonini beradi. Shu tufayli qiymat o'zgarganda butun komponent emas, faqat tegishli DOM tuguni yangilanadi.

Komponentlar

Zarra'da komponent — shablon qaytaruvchi oddiy funksiya. Props — funksiya argumentlari, holat — yopilma (closure) ichidagi signal'lar.

Birinchi komponent

TodoItem.js
export function TodoItem({ matn, bajarildi }) {
  return () => `
    <li class="${bajarildi() ? 'done' : ''}">
      <input type="checkbox" @model=${bajarildi} />
      <span>${matn}</span>
    </li>
  `
}
